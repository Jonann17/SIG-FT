# Glossario

| Termo | Significado |
|---|---|
| **AT** | Atualização Tecnológica — o programa de modernizacao |
| **CMI** | Consórcio de Modernizacao de Itaipu |
| **IB** | Itaipu Binacional |
| **ET** | Especificação Técnica. Delimita uma área do projeto. Ver [[Estrutura ET, Capitulo e Sistema]] |
| **PMIB** | Portal de Materiais da Itaipu Binacional |
| **PDM** | Padrão de Descrição de Material. Um por tipo de material (~1174-1193 no catalogo). Define quais características técnicas aquele tipo exige. Ver [[PDM - Padrao de Descricao de Material]] |
| **Ficha Técnica** | A ficha criada e preenchida no PMIB com base num PDM. Ver [[Anatomia de uma Ficha Tecnica]] |
| **Planilha PMIB** | Extrato em Excel dos campos do PDM (logistica + financeiro + características) que o CMI manda ao fornecedor preencher |
| **Lista STATUS PMIB** | Copia da lista de sobressalentes emitida, com colunas extras de gerenciamento. Ver [[Planilha STATUS_PMIB]] |
| **Tabela com Preços Unitarios / Lista de Preços** | Documento Aconex que valida o preço, substituindo a nota fiscal. Ver [[Lista de Precos]] |
| **Mapeamento dos Documentos de Referência** | Lista que amarra cada item da lista aos desenhos onde ele aparece. Insumo da [[Secao - Aplicacao LMR]] |
| **LMR** | Lista de Materiais de Reposicao. No portal, a aba "Aplicação - LMR" |
| **MTA** | Sistema de cadastro de material e geração de etiqueta de entrega |
| **RDS-PP** | Sistema de codificação de referência usado no projeto. Ver [[RDS-PP e KKS]] |
| **KKS** | Sistema de codificação que serve de base ao código interno do CMI |
| **Aconex** | Plataforma de gestão documental do projeto |
| **Almoxarifado de Itaipu** | Armazém administrado pela IB — destino dos sobressalentes |
| **Almoxarifado do CMI** | Armazém administrado pelo CMI — os sobressalentes **não** devem passar por ele |
| **CAP** | Certificado de Aceitação Provisoria. O fornecimento deve ser garantido por 10 anos após ele |
| **SAP ECC 6.07** | ERP da Itaipu, destino final da carga dos dados de PDM |
| **SOM** | Sistema legado de Itaipu citado na ET, antecessor do PMIB para catalogacao |
| **SIG-FT** | Sistema Integrado de Gestão de Fichas Técnicas — o app que automatiza tudo isso. Ver [[SIG-FT - Visao Geral]] |
| **Ficha duplicada** | Ficha para material idêntico já existente em outra lista. Usa `PDM.9900.000`. Ver [[Fichas Duplicadas]] |
